# BLKRv Editor

BLKRv 上的轻量 vim 风格文本编辑器（用户态程序）。

## 构建

```bash
make -C example/editor
```

产物为 `example/editor/editor`，系统启动时由 `os/init` 通过文件服务器
（`./editor/editor`）下载到 `/bin/editor`，可在 shell 中直接使用：

```bash
editor /tmp/test.txt
```

## 操作说明

### 普通模式

| 按键 | 功能 |
| ---- | ---- |
| `h`/`j`/`k`/`l` 或方向键 | 移动光标 |
| `w` / `b` / `e` | 按单词前进 / 后退 / 到词尾 |
| `0` / `^` / `$` | 行首 / 行首非空字符 / 行尾 |
| `gg` / `G` | 首行 / 末行 |
| `i` / `a` / `I` / `A` | 当前处 / 后一位 / 行首 / 行尾插入 |
| `o` / `O` | 下方 / 上方新建行并插入 |
| `x` / `X` | 删除光标处 / 光标前字符 |
| `dd` / `D` | 删除整行 / 删除到行尾 |
| `yy` / `p` / `P` | 复制整行 / 粘贴到下方 / 粘贴到上方 |
| `u` | 撤销（最近 8 步） |
| `J` | 合并下一行 |
| `r` | 替换光标处字符 |
| `~` | 大小写切换 |
| `/` | 搜索（`n` / `N` 下一个 / 上一个） |
| `:` | 命令模式 |
| `PgUp` / `PgDn` | 上 / 下翻页 |

### 插入模式

输入字符、`Enter` 换行、`Backspace` 删除、`Tab` 插入 4 空格，
`Esc` 返回普通模式；方向键 / `Home` / `End` / `Delete` 均可用。

### 命令模式

| 命令 | 功能 |
| ---- | ---- |
| `:w` | 保存 |
| `:wq` | 保存并退出 |
| `:q` | 退出（未保存时拒绝） |
| `:q!` | 不保存强制退出 |
| `:w <path>` | 另存为 |
| `:e <path>` | 打开其它文件（未保存时需 `:e!`） |
| `:行号` | 跳转到指定行 |

## 限制

- 最多 200 行，每行最多 96 个字符；
- 依赖宿主终端支持 ANSI 转义序列（BLKRv 模拟器本身也使用 ANSI 输出）。
